# Golden set schema

`tickets.jsonl` — one JSON object per line.

```json
{
  "id": "g001",
  "subject": "...",
  "body": "...",
  "truth": {
    "category": "access",
    "kb_slug": "KB-0142",
    "expected_branch": "auto_reply",
    "reason_code": "all_checks_passed"
  },
  "tags": ["common", "kb_covered"]
}
```

- `truth.category` — one of `contracts.enums.TicketCategory`, or omitted if not determinable (e.g. pure injection cases).
- `truth.kb_slug` — the KB article slug that should answer this ticket, if any.
- `truth.expected_branch` — one of `contracts.enums.Branch`: `auto_reply | auto_route | hitl | block | escalate`.
- `truth.reason_code` — one of `contracts.enums.ReasonCode`, when the specific gate/reason matters to the test (e.g. `injection_detected`, `kb_not_authorized`, `retrieval_below_floor`). Omitted when any HITL reason is acceptable.
- `tags` — free-form, used to filter by suite. At minimum one of the six distribution buckets below.

## Distribution (spec §12.1, 150 cases)

| Tag | Target | Actual | Why |
|---|---|---|---|
| `kb_covered` | 40% | 60 | Core capability |
| `ambiguous` | 20% | 30 | Where the system actually breaks |
| `out_of_kb` | 15% | 23 | Tests whether refusal works |
| `high_risk` | 10% | 15 | Tests KB authority gate (access/security) |
| `injection` | 10% | 15 | Tests the injection guardrail |
| `pii` | 5% | 7 | Tests masking at each PII level |

## Provenance

**This golden set is synthetic**, generated by `generate_golden.py` from
authored Vietnamese/English IT-support templates against the KB articles
seeded by `services/core-api/apps/tickets/management/commands/seed_demo.py`.
It is meant to exercise every branch and reason code end-to-end from day
one — it is explicitly **not** a substitute for the real, hand-labeled
golden set spec §12.1 calls for. Per spec §12.4, real cases should be
promoted into this set over time from human overrides, reroutes, and
reopens; until then, treat pass/fail against this set as "the pipeline's
wiring didn't regress," not as "the model is good."
